# @better-media/adapter-db-drizzle

Drizzle ORM `DatabaseAdapter` for Better Media (PostgreSQL, MySQL, SQLite).

```ts
import { drizzleAdapter, DrizzleDbAdapter } from "@better-media/adapter-db-drizzle";
```

Install `drizzle-orm` and your driver (`pg`, `mysql2`, or `better-sqlite3`) in your app as needed.
