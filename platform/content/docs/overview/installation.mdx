<Steps>
  <Step>
    ### Install Better Media

    <Tabs groupId="docs-package-manager" items={['pnpm', 'npm', 'yarn']} persist>
      <Tab value="pnpm">
        ```bash
        pnpm add @better-media/framework
        ```
      </Tab>

        ```bash
        npm install @better-media/framework
        ```
      </Tab>
      <Tab value="yarn">
        ```bash
        yarn add @better-media/framework
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step>
    ### Install a storage adapter

    For this example we'll use S3, which works with AWS S3, Cloudflare R2, MinIO, and any S3-compatible provider.

    <Tabs groupId="docs-package-manager" items={['pnpm', 'npm', 'yarn']}>
      <Tab value="pnpm">
        ```bash
        pnpm add @better-media/adapter-storage-s3
        ```
      </Tab>
      <Tab value="npm">
        ```bash
        npm install @better-media/adapter-storage-s3
        ```
      </Tab>
      <Tab value="yarn">
        ```bash
        yarn add @better-media/adapter-storage-s3
        ```
      </Tab>
    </Tabs>

    <Callout type="info" title="Other storage options">
      Filesystem and in-memory adapters are also available. See the [Storage](/docs/storage) section for all options.
    </Callout>
  </Step>

  <Step>
    ### Install a database adapter

    <Tabs groupId="docs-package-manager" items={['pnpm', 'npm', 'yarn']}>
      <Tab value="pnpm">
        ```bash
        pnpm add @better-media/adapter-db-kysely pg
        ```
      </Tab>
      <Tab value="npm">
        ```bash
        npm install @better-media/adapter-db-kysely pg
        ```
      </Tab>
      <Tab value="yarn">
        ```bash
        yarn add @better-media/adapter-db-kysely pg
        ```
      </Tab>
    </Tabs>

    <Callout type="info" title="Other databases">
      MongoDB, MySQL, and SQLite are also supported. See the [Database](/docs/database) section for setup guides.
    </Callout>
  </Step>

  <Step>
    ### Set environment variables

    Add your storage and database credentials to your `.env` file:

    ```bash
    # S3 Storage
    AWS_REGION=us-east-1
    AWS_ACCESS_KEY_ID=your-access-key
    AWS_SECRET_ACCESS_KEY=your-secret-key
    S3_BUCKET=your-bucket-name

    # Database
    DATABASE_URL=postgres://user:password@localhost:5432/mydb
    ```
  </Step>

  <Step>
    ### Configure the database adapter

    Set up Kysely with your Postgres connection:

    ```ts title="lib/database.ts"
    import { Pool } from "pg";
    import { Kysely, PostgresDialect } from "kysely";
    import { KyselyDbAdapter } from "@better-media/adapter-db-kysely";
    import { schema } from "@better-media/core";

    const db = new Kysely({
      dialect: new PostgresDialect({
        pool: new Pool({ connectionString: process.env.DATABASE_URL }),
      }),
    });

    export const database = new KyselyDbAdapter(db, {
      config: { provider: "pg" },
      schema,
    });
    ```
  </Step>

  <Step>
    ### Create a Better Media instance

    Wire your storage, database, and plugins together in one place:

    ```ts title="lib/media.ts"
    import { createBetterMedia } from "@better-media/framework";
    import { S3StorageAdapter } from "@better-media/adapter-storage-s3";
    import { database } from "./database";

    export const media = createBetterMedia({
      storage: new S3StorageAdapter({
        region: process.env.AWS_REGION!,
        accessKeyId: process.env.AWS_ACCESS_KEY_ID!,
        secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY!,
        bucket: process.env.S3_BUCKET!,
      }),
      database,
      plugins: [],
    });
    ```

    Import `media` anywhere in your app — route handlers, workers, scripts.
  </Step>

  <Step>
    ### Create database tables

    Better Media manages its own tables. Run the migration CLI to apply them:

    <Tabs groupId="docs-package-manager" items={['pnpm', 'npm', 'yarn']}>
      <Tab value="pnpm">
        ```bash
        pnpm exec media migrate
        ```
      </Tab>
      <Tab value="npm">
        ```bash
        npx media migrate
        ```
      </Tab>
      <Tab value="yarn">
        ```bash
        yarn media migrate
        ```
      </Tab>
    </Tabs>

    Or run migrations programmatically on app startup:

    ```ts
    import { runMigrations } from "@better-media/core";
    import { database } from "./lib/database";
    import { schema } from "@better-media/core";

    await runMigrations(database, schema);
    ```
  </Step>

  <Step>
    ### You're ready

    Your `media` instance is ready to use. Upload your first file:

    ```ts
    import { media } from "./lib/media";

    const result = await media.upload.ingest({
      file: { buffer: fileBuffer },
      metadata: { filename: "photo.jpg", mimeType: "image/jpeg" },
    });

    console.log(result.id, result.key);
    ```

    From here, explore [plugins](/docs/plugins) to add validation, virus scanning, or image processing to the pipeline.
  </Step>
</Steps>
