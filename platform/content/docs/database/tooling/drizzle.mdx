title: Drizzle
description: Using Drizzle alongside Better Media — keeping your app schema in Drizzle while Better Media manages its own tables via the Kysely adapter.
---

Better Media does not integrate with Drizzle directly — it uses its own Kysely-based adapter for the five media tables. The recommended pattern is to use both side-by-side: Drizzle for your application tables, the Kysely adapter for Better Media tables. Both point at the same database.

## Setup

Install both adapters:

```bash
pnpm add drizzle-orm @better-media/adapter-db-kysely kysely
# choose your driver — e.g. postgres.js for Postgres
pnpm add postgres
```

Configure them separately:

```typescript
import postgres from "postgres";
import { drizzle } from "drizzle-orm/postgres-js";
import { Pool } from "pg";
import { Kysely, PostgresDialect } from "kysely";
import { KyselyDbAdapter } from "@better-media/adapter-db-kysely";
import { schema } from "@better-media/core";

// Drizzle — for your application tables
const queryClient = postgres(process.env.DATABASE_URL!);
export const db = drizzle(queryClient);

// Better Media — for media tables (same database, separate connection pool)
const pool = new Pool({ connectionString: process.env.DATABASE_URL });
const kyselyDb = new Kysely({ dialect: new PostgresDialect({ pool }) });
const bmDatabase = new KyselyDbAdapter(kyselyDb, {
  config: { provider: "pg" },
  schema,
});

export const media = createBetterMedia({
  storage,
  database: bmDatabase,
  plugins,
});
```

## Migrations

Drizzle and Better Media manage separate sets of tables — their migration systems do not overlap.

- **Your application tables** → managed by Drizzle Kit (`drizzle-kit push` or `drizzle-kit generate`)
- **Better Media tables** → managed by the Better Media CLI or `runMigrations()`

Run both as part of your deployment:

```bash
# 1. Apply your app schema
npx drizzle-kit push

# 2. Apply Better Media schema
npx better-media migrate --yes
```

Or programmatically on startup:

```typescript
import { migrate } from "drizzle-orm/postgres-js/migrator";
import { runMigrations } from "@better-media/core";

// Your app migrations
await migrate(db, { migrationsFolder: "./drizzle" });

// Better Media migrations
await runMigrations(bmDatabase, schema);
```

## Accessing Media Records from Drizzle

Better Media tables are plain SQL tables. If you want to query them from Drizzle (e.g. to JOIN media records with your own user table), you can define the Better Media tables in your Drizzle schema manually:

```typescript
import { pgTable, text, integer, timestamp } from "drizzle-orm/pg-core";

export const media = pgTable("media", {
  id: text("id").primaryKey(),
  filename: text("filename"),
  mimeType: text("mime_type"),
  size: integer("size"),
  status: text("status"),
  createdAt: timestamp("created_at"),
  // add only the columns you need to query
});
```

Define only the fields you need to query. Do not manage migrations for these tables through Drizzle — let Better Media own them.
